# Repositorio de Comprensión Lectora · 2.º grado de primaria

Sitio estático listo para publicarse con GitHub Pages. El archivo de entrada es `index.html`.

## Recursos incluidos

- Comprensión literal: cinco lecturas PDF y sus cinco talleres PDF.
- Comprensión inferencial: cinco lecturas PDF y sus cinco talleres PDF.
- Videos: siete videos MP4 con miniaturas de vista previa.
- Las lecturas y sus talleres comparten la misma miniatura.
- Los PDF se pueden abrir dentro del repositorio en una ventana emergente o descargar desde su tarjeta.
- Los videos se reproducen dentro de una ventana emergente con controles del reproductor.

### Orden de los videos

1. Consejos para leer y comprender un texto
2. La gallina Yina
3. La pequeña luna y la lluvia
4. La cometa
5. La detective Susana
6. La gatita Catalina
7. Pancho el glotón

## Publicación en GitHub Pages

1. Copia el contenido de esta carpeta a la raíz de tu repositorio de GitHub.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

Los favoritos y el registro local de visitas se guardan en el navegador de cada dispositivo, como en la versión anterior del repositorio.
