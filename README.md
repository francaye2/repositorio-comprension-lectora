# Repositorio de Comprensión Lectora · 2.º grado de primaria

Sitio estático preparado para publicarse en GitHub Pages. El archivo de entrada es `index.html`.

## Contenido incluido

- Comprensión literal: cinco lecturas y cinco talleres en PDF.
- Comprensión inferencial: cinco lecturas y cinco talleres en PDF.
- Videos: siete videos MP4 con sus miniaturas.
- Las lecturas y sus talleres comparten la misma miniatura.
- Los PDF se abren dentro del repositorio en una ventana emergente y también pueden descargarse.
- Los videos se reproducen en una ventana emergente y sus tarjetas no tienen botón de descarga.
- La sección Ayuda incluye siete tarjetas de orientación y cinco preguntas frecuentes.
- La hoja de estilos incluye reglas responsive para teléfonos, tabletas y computadores.

## Orden de los videos

1. Consejos para leer y comprender un texto
2. La gallina Yina
3. La pequeña luna y la lluvia
4. La cometa
5. La detective Susana
6. La gatita Catalina
7. Pancho el glotón

## Publicar con GitHub Pages

1. Copia el contenido de esta carpeta en la raíz del repositorio de GitHub.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

Los favoritos y el registro de visitas mantienen el comportamiento local del repositorio: se guardan en el navegador del dispositivo y no se sincronizan entre equipos.
